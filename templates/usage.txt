ralph — Autonomous task executor. Loops Claude Code over beads issues.

Usage: ralph [OPTIONS]
  --dry-run            Show next task without executing
  --max-tasks N        Stop after N tasks completed (default: unlimited)
  --max-loops N        Stop after N Claude invocations (default: 50)
  --timeout N          Minutes per Claude invocation (default: 10)
  --scope PATTERN      Only work issues matching regex pattern
  --playlist FILE      Execute tasks from playlist file (mutually exclusive with --scope)
  --queue [FILE]       Run multiple playlists in sequence; one child ralph per
                       entry (default: .ralph/queue)
  resume, --resume     Resume whatever was running last from .ralph/state.
                       If queue_file is set, resumes the queue at queue_index.
                       Else if playlist_file is set, resumes at playlist_line.
  --no-commit          Tell Claude not to commit per-task (playlist default)
  --commit             Tell Claude to commit per-task (overrides playlist default)
  --playlist-branch N  Override playlist branch name (default: from file or filename)
  --sandbox            Wrap Claude in bubblewrap sandbox (Linux only)
  --model MODEL        Claude model to use (default: config.sh)
                       GLM models supported: glm-4.5, glm-4.7, glm-5, etc.
  --context-files LIST Comma-separated project files for prompt manifest
  --monitor            Live dashboard in a separate terminal
  --tmux, -t           Wrap execution in a detachable tmux session
  --remote [HOST], -r  Run on remote server via SSH+tmux
  --init               Create .ralph/ directory with default config
  --status             Print current state and exit
  --reset              Clear circuit breaker and loop state
  -h, --help           Show this help
